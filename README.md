## Featured Project — DataHealth AI

**An end-to-end healthcare data and AI prototype built with synthetic HL7 FHIR R4 records.**

**[Open Live Application](https://datahealth-ai.streamlit.app/)** | **[Explore Source Code & Documentation](https://github.com/LucaBarsi/DataHealth-AI)**

- **112 synthetic patients** available through an interactive Streamlit web application.
- **Clinical Assistant** combining patient-scoped SQL queries, document retrieval (RAG), and Qwen 3.5 4B, with source identifiers and evidence inspection.
- **Analytics Dashboard** for exploring synthetic records, measurements, and data-quality findings.
- **ML Forecasting** for exploratory analysis of aggregate synthetic encounter volumes.
- **Engineering workflow** covering FHIR-derived transformations, a SQLite Gold Layer, ChromaDB retrieval, and separate local PySpark/Parquet experiments.

**Tech stack:** Python · SQL/SQLite · Pandas · Streamlit · Plotly · ChromaDB · FastEmbed · Qwen · Scikit-learn · PySpark · GitHub

> **Research and portfolio prototype.** Synthetic data only. Not designed for real patient information, diagnosis, treatment, or clinical decision-making. Verified citation IDs do not guarantee medical or factual accuracy.

## Other Selected Projects

### [Diabetes Prediction — Biochemical Tests & Clinical History](https://github.com/LucaBarsi/diabetes-prediction)

End-to-end supervised machine learning for a public diabetes dataset, including exploratory data analysis, documented preprocessing decisions, model comparisons, and hyperparameter tuning.

**Reported test results:** tuned XGBoost with **ROC-AUC 0.977** and **recall 0.917** for the diabetic class. Results are dataset-specific and not a clinically validated diagnostic model.

### [Microorganism Image Classification](https://github.com/LucaBarsi/microorganism-image-classifier)

Deep learning image-classification experiment using **MobileNetV2 transfer learning** to distinguish eight classes of microorganisms in microscopy images. Includes augmentation, evaluation, and discussion of limitations from a small dataset.
