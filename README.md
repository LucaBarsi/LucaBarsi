## 📌 Featured project

### [Diabetes Prediction — Biochemical Tests and Clinical History](https://github.com/LucaBarsi/diabetes-prediction)

End-to-end classification pipeline predicting diabetes from lab tests
(glucose, HbA1c) and clinical history. Covers documented data-cleaning
decisions, comparison of three models (Logistic Regression, Random Forest,
XGBoost), hyperparameter tuning, and a final model chosen with an explicit
metric trade-off — not just picking the "highest accuracy" option.

**Result:** tuned XGBoost, ROC-AUC of 0.977, recall of 0.917 on the diabetic class.
